# HackMatch · 校园黑客松组队与项目提交平台

社团每次办黑客松，报名后组队全靠群里吼，项目链接到处飞，组织者也看不到进度。
HackMatch 就是冲着这几个痛点做的一个小工具。

## 怎么用

双击 `index.html` 就能打开。

想重置数据：浏览器按 F12 → Application → Local Storage → 删掉 `hackmatch.db.v1` → 刷新。

## 技术栈

- 原生 HTML / CSS / JavaScript，没有框架
- 数据存在浏览器的 localStorage 里
- 单文件，无构建步骤

## 功能

1. **活动报名**：填姓名、年级、技能标签、想做的方向、可投入时间、联系方式
2. **组队大厅**：按缺口角色和项目方向筛选队伍
3. **申请加入**：提交申请后由队长审核，支持通过 / 拒绝
4. **项目提交**：队长交作品（项目名、简介、GitHub 仓库、Demo 链接），进作品墙展示
5. **智能推荐**：根据技能互补和方向兴趣推荐队伍和队友
6. **数据看板**：组织者查看报名数、队伍数、提交数、技能分布

## 匹配算法

先做同义词归一（"大模型" / "LLM" / "RAG" 都归为 `ai`），然后打分：

**队伍推荐** = 技能补缺口 × 3 + 方向兴趣重合 × 2 + 有空位 × 1

**队友推荐** = 互补技能 × 2 + 方向重合 × 2 + 共同技能 × 1

技能补缺口权重最高，因为组队的核心诉求就是"我有的正是你缺的"。

## 关于演示数据

网页首次打开时，会自动带一批演示数据，方便直接看到完整效果：

- 6 个示例用户（林小满、陈锐、王雨桐、赵一鸣、孙可、周墨）
- 3 支示例队伍（夜猫子、智谱小队、硬件敢死队）
- 几条示例申请记录

**这些数据是写死在代码里的演示内容，只存在浏览器的 localStorage 里，
不是从服务器拉的真实数据，也不会同步给任何人。**

首次打开时，代码里的 `seed()` 函数会自动把这些数据写进 localStorage。

如果你想要一个干净的空页面：
1. 打开网页，按 F12
2. Application → Local Storage → 删除 `hackmatch.db.v1`
3. 同时，在 `index.html` 里搜索 `function seed`，
   把 `users`、`teams`、`members` 三个数组清空（改成 `[]`）
4. 刷新页面

演示时建议先手动报一次名、建一支队，
屏幕上有真实操作痕迹，效果更好。
